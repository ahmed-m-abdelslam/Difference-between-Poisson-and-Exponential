# 📊 Poisson vs Exponential Distributions

This project visualizes and compares two important probability distributions used in Data Science and Statistics:

- **Poisson Distribution** – models the number of events in a fixed interval  
- **Exponential Distribution** – models the time between events

---

## 📈 What’s Inside

This Python script uses `matplotlib` and `scipy.stats` to:

- ✅ Plot a **discrete** Poisson distribution  
- ✅ Plot a **continuous** Exponential distribution  
- ✅ Show how both are related through the parameter **λ (lambda)**

---

## 🧠 Why This Matters

Understanding the difference between Poisson and Exponential distributions is essential for:

- Queueing theory  
- Event modeling (e.g., website visits, phone calls)  
- Survival analysis  
- Time-to-failure systems
